# Tailwind CSS for client styling, fully migrated

The client's visual redesign (illustrated pirate-nautical theme, gold/parchment palette, themed type scale) needs a real design-token system, and we're introducing per-screen styling at a larger scale than the current single 147-line `index.css`. We chose Tailwind CSS over hand-written CSS custom properties, even though the app is small enough that plain CSS would have been the lower-migration-cost option — the explicit trade-off was faster iteration on utility combinations and built-in responsive/state variants, against the cost of a new build dependency and rewriting every existing screen's styles. All of `index.css`'s existing rules are migrated into Tailwind theme config and utility classes rather than left running alongside Tailwind, to avoid two styling systems coexisting.
